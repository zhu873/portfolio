01 / Discovery Pulse

用更有节奏感的方式组织洞察信息

这个作品更偏向信息探索与洞察呈现。我希望它在“内容组织”与“浏览节奏”之间取得平衡，让用户不只是看见信息，而是被引导着逐步发现结构。

  • 定位：Insight / Exploration
  • 关注点：信息层级、节奏感、视觉引导
  • 角色：独立设计与实现

02 / Short Drama LLM

把短剧叙事和 LLM 体验结合起来

这个项目聚焦于“叙事体验”与“生成式互动”的结合。相比传统工具型页面，它更强调情绪推进、角色感和故事结构，让用户感受到内容是如何被生成与展开的。

  • 定位：Narrative / LLM Experience
  • 关注点：剧情节奏、互动反馈、角色感
  • 角色：独立设计与实现

03 / Meditation in Peace

一个强调听觉与舒缓动态的减压页面

这是一个更情绪化、也更轻盈的作品。我希望页面能在极简视觉里提供安静、柔和、可停留的体验，让音频、计时和细微动画一起构成节奏。

  • 定位：Wellness / Ambient Interaction
  • 关注点：氛围感、停留感、柔和动效
  • 角色：独立设计与实现
